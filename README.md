# Xiaoyue Zhang · Personal website

Open index.html in a browser to preview the site locally. The site uses HTML and CSS and has no build dependencies.

## Publish on GitHub Pages

1. Create a repository named YOUR-USERNAME.github.io for a personal site, or use a repository dedicated to this portfolio.
2. Place index.html, styles.css, and .nojekyll at the root of the main branch.
3. In the repository, open Settings → Pages. Under Build and deployment, choose Deploy from a branch, select main and /(root), then save.
4. When deployment completes, visit the URL shown in Settings → Pages.

Edit index.html to update your profile. Edit styles.css to change the layout and colors.

[Official GitHub Pages quickstart](https://docs.github.com/en/pages/quickstart)
